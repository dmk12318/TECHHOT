# DAILY HOT

**TECH HOT** —— 面向「有阅读新闻需求与习惯的公职人员」的中文科技新闻站。
科技是第一个板块，做熟后复制到其他板块；六个板块**各自独立成站**，
最后用 DAILY HOT 做一个导航页把它们串起来（见 `records/决策记录.md` 2026-10-10）。
