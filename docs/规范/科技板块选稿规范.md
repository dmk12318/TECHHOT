## 一、判断标准：值不值得让读者花 30 秒

三条同时成立才算值得上：

1. **有确定的新事实**：某家公司、机构或主管部门做了一件具体的事
   （发布、获批、量产、涨价、处罚、下线、召回、事故、合作）。
2. **影响面超出当事方**：会改变普通读者买得到的东西、用得上的服务、看到的价格，
   或者行业的公开规则。
3. **不需要技术背景就能听懂**：能写清「这跟我有什么关系」。

判断「不重要」最常见的原因：只有参数和跑分、只有行业会议上的表态、
只有公司内部的组织调整、只是别人报道过的二次解读。

## 二、类别与边界

科技边界取门户意义上的科技，分成六个类别（方案与理由见 `类别方案.md`）：

| 类别 | 收什么 | 不收什么 |
| --- | --- | --- |
| 人工智能 | 模型、算力、AI 产品与治理；原「互联网平台」的内容也并到这里 | 单个 App 的小版本更新、纯参数对比 |
| 消费电子 | 手机、电脑、平板、可穿戴、家电的发布与定价、系统更新的影响面、召回 | 单个配件发售、渠道促销、开箱测评 |
| 半导体 | 芯片设计与制造、制程、产能、出口管制、设备与材料、涨价缺货 | 纯学术论文、产线开工剪彩 |
| 通信 | 运营商资费与网络建设、5G/6G 进展、卫星互联网、频谱与监管 | 设备商的常规招标公告 |
| 汽车与新能源 | 车企价格与技术路线、辅助驾驶的法规与事故调查、召回；光伏、储能、电池、电价与补贴政策 | 车评、试驾、赛道成绩、单个项目的环评公示 |
| 观点与解读 | 评论、解读、预测（引擎里的评论类，日报只放快讯） | 无新事实的转载 |

## 三、必须正常评价的（出现就别压）

- **官方发布**：公司或主管部门正式发布的产品、政策、标准。
- **监管与政策**：网信、工信、市场监管、能源局等的新规、征求意见稿、处罚决定。
- **价格与供应**：涨价、降价、缺货、产能变化——读者能直接感受到的。
- **安全与事故**：召回、漏洞被利用、大规模故障、数据泄露。
- **里程碑**：首个、首次、份额第一、量产下线这类有硬数据支撑的。

## 四、必须压住的（出现就扣）

- **纯参数与跑分**：没有使用场景、价格或上市信息的性能提升。
- **会议与演讲**：峰会发言、论坛观点，除非当事方当场宣布了具体事项。
- **观点与预测**：分析师展望、行业趋势预判、自媒体解读。
- **教程与体验**：上手、评测、教程、开箱。
- **营销**：预售、促销、联名、代言、渠道合作。
- **榜单与盘点**：「十大」「盘点」「回顾」这类汇总。
- **旧闻重发**：原始事件早于本次发布时间的转载、编译、二次解读。
- **来源不明的传闻**：只有「据知情人士」而没有当事方回应的。

## 五、内容类型与权重方向

引擎按内容类型给评分维度不同的权重。科技板块的方向：

| 类型 | 方向 | 说明 |
| --- | --- | --- |
| 发布（产品 / 政策 / 标准） | 高 | 一手来源优先 |
| 监管与处罚 | 高 | 影响面广、确定性高 |
| 事故与安全 | 高 | 时效性强，但要有官方或权威来源 |
| 供应链与价格 | 中高 | 要有具体数字 |
| 技术进展 | 中 | 有明确应用或落地节点才给中高 |
| 观点评论 | 低 | 只有当事方自己的新动作才加分 |
| 教程与体验 | 低 | 基本不进精选 |

具体数值等评分提示词写好后，用 Gold 样本校准，不在这里写死。
