1. 歧义默认值：以下中文词有非科技含义，**一律按科技含义翻译**：
   - Chip / Chips = 芯片（不是“薯条”“筹码”）
   - Model = 模型（不是“模特”“型号”，除非原文明确指车型或机型）
   - Battery = 电池与续航（不是“殴打”“一系列”）
   - Recall = 召回（不是“回忆”“撤销”）
   - Agent = 智能体（不是“代理人”“中介”）
   - Terminal = 终端（不是“航站楼”）
   - Yield = 良率（芯片制造语境）
   - Band = 频段；Slot = 卡槽或时段，按上下文取一个
   - Charge / Charging = 充电、计费（按上下文取一个，同一篇里保持一致）
   - Platform = 平台（不是“站台”）
   - Patch = 补丁或更新，不用“贴片”
   - Token = 保留英文（不译“代币”“令牌”）
   - Alignment = 对齐（人工智能安全语境）
   - Inference = 推理（模型生成）；Reasoning = 推理（必要时用“链式推理”区分）
   - Hallucination = 模型幻觉；Fine-tune = 微调；Context window = 上下文窗口
