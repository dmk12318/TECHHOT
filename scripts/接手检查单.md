# 接手检查单

新对话开场直接用这段，替换尖括号内容：

```text
读 <项目路径>\AGENTS.md 和 <项目路径>\.handoff\PROJECT_STATE.md。
本次目标：<要做什么>
验收标准：<怎么算做完>
不要重做已经验证过的部分；如果材料与项目现状冲突，先告诉我冲突点再动手。
```

接手方按这个顺序做：

1. 读 `AGENTS.md` → 知道规则和边界
2. 读 `.handoff/PROJECT_STATE.md` → 知道进度和下一步
3. 读本次任务相关的 `docs/规范/` → 知道标准
4. 检查材料与现状是否一致，**有不一致先说，不要硬着头皮做**
5. 确认第一步后开工
